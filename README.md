# Elgravion TCG

Gioco di carte del mondo di Elgravion. Si gioca nel browser e si può installare come app (PC, Android, iPhone).

## Pubblicare online
Carica **tutto il contenuto** di questa cartella (index.html in cima) su un hosting statico HTTPS:
- **GitHub Pages**: repository → Settings → Pages → Branch `main`, cartella `/ (root)`.
- **Netlify Drop** (app.netlify.com/drop): trascina la cartella.

## Installare
- PC (Chrome/Edge): icona “Installa” nella barra degli indirizzi.
- Android (Chrome): menu ⋮ → “Installa app”.
- iPhone (Safari): Condividi → “Aggiungi alla schermata Home”.

Dopo il primo avvio funziona anche offline. Quando esce una nuova versione compare il pulsante “Aggiorna”.

Collezione, mazzi e progressi restano salvati sul dispositivo. Online e Classificata non sono ancora attivi nella versione scaricabile.
